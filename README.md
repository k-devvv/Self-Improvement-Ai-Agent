# Self-Improvement AI Agent

A universal agent that learns any kind of work as a skill, proves each one against an answer key, turns the proven ones into paid offers, and puts more effort into whichever skill earns. A local model does the work, Claude grades it, and a weekly coach proposes one change you approve.
